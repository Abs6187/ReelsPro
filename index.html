ReelsPro

A platform where users can share and watch short videos with AI-powered features, content moderation, and seamless user experience designed for connection and creativity.

Project Overview

ReelsPro is a comprehensive short video platform that combines social media functionality with advanced AI features. It includes an intelligent chatbot for user assistance and a sophisticated content moderation system to ensure a safe and engaging environment. The platform is designed with user experience at its core, making it fun and easy to use while helping people connect through their creative videos.

Key Features

User-friendly Interface Seamless feedback submission and intuitive navigation
Video Upload & Rendering Powered by ImageKit for optimal performance
AI Chatbot Intelligent assistance using Groq and Vercel AI SDK
Content Moderation AI-powered moderation with Gemini and Groq
Mobile Responsive Accessible across all devices and screen sizes
Optimized Performance SSR and SSG for lightning-fast loading
Modern UI Beautiful design with Tailwind CSS and Shadcn
Secure API Protected interactions ensuring data integrity

Installation & Setup

Prerequisites

  • Node.js (Latest LTS version recommended)
  • npm or yarn for package management

Environment Configuration

Create a .env file in the root directory with the following variables:

NEXT_PUBLIC_PUBLIC_KEY=<your-imagekit-next-api-key> IMAGEKIT_PRIVATE_KEY=<your-imagekit-private-api-key> NEXT_PUBLIC_URL_ENDPOINT=<your-imagekit-url-endpoint> GROQ_API_KEY=<your-groq-api-key> GROQ_API_MODEL=<your-groq-api-model>

Development Server

npm run dev # or yarn dev

Open http://localhost:3000 in your browser to view the application.

Future Integrations

What makes ReelsPro different from existing platforms:

  • Safe Content Environment: Daily vlog uploads without fear of inappropriate content
  • Advanced AI Integration: Automatic tagging, moderation, and personalized feeds beyond basic AI features
  • Seamless Media Optimization: Drag-and-drop uploads with real-time optimization via ImageKit
  • Platform-Agnostic Backend: Developers can build custom video applications
  • Serverless Architecture: Scalable deployment for cost-effective growth
  • Creator Analytics: Actionable insights and future monetization support
